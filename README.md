# AI-Driven Grid India Level Energy Demand Forecasting

## Overview

This project develops an Artificial Intelligence based Electricity Demand Forecasting System using historical Grid India data collected at 15-minute intervals.

The application provides

- Data Collection
- Data Preprocessing
- Feature Engineering
- Exploratory Data Analysis
- Machine Learning
- Deep Learning
- Model Comparison
- Demand Forecasting
- Performance Reports

---

## Machine Learning Models

- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

---

## Deep Learning Models

- Gated Recurrent Unit (GRU)
- Bidirectional LSTM (Bi-LSTM)
